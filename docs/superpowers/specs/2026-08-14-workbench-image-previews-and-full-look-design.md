# 工作台图片预览与整套换装设计

## 目标

让一手工作台的任务组更直观地展示已上传图片，并支持每组最多五张模特图；新增“整套换装”模式，把一张穿搭参考图中的完整服装换到每张目标模特图上。

## 用户界面

- 每个已上传资源都显示缩略图、角色名称与原始文件名。
- “上装 + 下装”模式保留现有上装、下装与模特图角色。
- “整套换装”模式显示一个“整套参考图”上传位和一个“模特图（最多 5 张）”上传位。
- 模特图支持一次选择多张或多次追加上传；前端按选择顺序编号 T01–T05。
- 选择超过五张时，前端不发起上传并显示中文提示。
- 缩略图使用安全的对象 URL，在组件卸载或图片替换时释放。

## 数据与交接

- 资产角色新增 `full_look`，只允许在整套换装模式使用。
- 现有 top、bottom、model 的数据、旧任务和交接文本继续有效。
- 模特图继续使用现有 `asset_ordinal`，确保结果合同、质检和交接文本按 T01–T05 稳定对应。
- 整套换装的交接文本明确：整套参考图仅用于服装外观，目标模特图是唯一编辑目标，必须保持身份、姿势、背景、鞋包与配饰不变。

## 校验与错误处理

- 服务器限制每组模特图片总数不得超过五张，防止绕过网页限制。
- 上传非图片、过大文件或不兼容模式时，沿用现有中文 API 错误提示。
- 删除任务组与既有图片清理逻辑不改变。

## 测试

- 为角色/模式校验与五张上限建立单元或接口测试。
- 为整套换装交接文案添加单元测试。
- 为客户端选择文件与缩略图映射提取可测试的纯函数，并覆盖五张正常输入和超限输入。
- 运行完整 Vitest 测试与生产构建。

## 非目标

- 本轮不接入自动图像生成 API；仍通过复制交接文案到 ChatGPT/Codex 完成换装。
- 本轮不修改已部署的密码、Supabase 架构以外的云端设置或既有任务数据。
