# 深色工作台与灵活成图质检设计

## 目标

将一手 AI 换装工作台调整为深色半透明玻璃界面，并让操作员能快速拖拽、预览、删除和替换所有任务图片。

## 界面

- 页面使用深灰黑渐变背景、半透明玻璃卡片、白色文字、圆角胶囊控件和少量玫红高光，参考用户提供的导航图风格。
- 任务日期卡默认展开；点击收起后仅保留显示当前日期和“展开任务”的小胶囊按钮。再次点击恢复日期选择与打开任务按钮。
- 素材卡、成图卡都保留现有缩略图预览；加入统一的删除按钮和拖拽高亮状态。

## 图片工作流

- 衣服图和模特图继续允许 JPG、PNG、WebP 拖拽或文件选择上传；草稿组中的素材可单张删除。
- 基准成图只允许 PNG。可拖入对应成图卡，先显示浏览器本地预览，再由操作员确认上传。
- 已上传的基准成图可删除；服务端删除该输出、其私有存储对象及关联人工质检记录。删除后该模型位置重新显示成图上传卡。

## 质检规则

- 服务器仍解析图片以确认它是可读取的 PNG，但不再将宽高与模特原图作 PASS/FAIL 比较。
- 任何可读取的 PNG 结果均保存为技术 PASS，因此可以进入现有人工一键通过流程。
- 文件名仍完全由服务器输出合同确定；操作员的本地文件名不参与校验。

## 数据与安全

- 新增一个版本锁定的删除输出 RPC：只删除指定 job/group/phase/attempt/output，删除前校验任务版本，返回要清理的私有 object key。
- 删除输出将级联删除 `reviews`，并更新 jobs.version。冲突时提示刷新；找不到的图片返回 404。
- 预览继续只能经已登录的私有 Storage 路由读取。

## 验证

- 为尺寸无关的技术状态、删除输出 RPC/API、成图拖拽 UI、日期收起 UI 写回归测试。
- 运行完整 Vitest 套件和 `npm run build`。
- 手工验证：拖入不同尺寸 PNG 后可快速通过；删除成图后缩略图和 QC 消失；收起/展开日期栏；手机和桌面宽度下均可操作。
